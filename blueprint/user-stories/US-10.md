# US-10 — See what was stored

**As a user**, after sending a message that triggers vault writes, I can see a summary of which pages were created or updated so that I know what was added to my wiki.

## Acceptance Criteria

- After a vault write, a collapsible "Saved to vault" summary appears inline beneath the assistant's response, both during live streaming and when the message is loaded from history.
- Each entry shows the vault-relative path of the page that was written.
- The summary is collapsed by default and can be expanded to see the full list of paths.
