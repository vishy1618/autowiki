# US-02 — Sign out

**As a user**, I can sign out of autowiki so that my session is ended and the interface is inaccessible until I sign in again.

## Acceptance Criteria

- After signing out, navigating to any route redirects to the sign-in page.
- My chat history and vault are not affected by signing out.

## Implementation Checklist

### Backend — Logout Endpoint (`internal/auth`)
- [x] Register `POST /api/auth/logout`
- [x] Delete the session token from Pebble
- [x] Clear the session cookie (set `Max-Age: -1`)
- [x] Return 200

### Frontend — Sign-out Button
- [x] Add a sign-out button to the main layout (visible on all authenticated routes)
- [x] On click, `POST /api/auth/logout` then redirect to `/login`
