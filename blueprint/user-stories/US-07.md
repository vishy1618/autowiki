# US-07 — Ask a question

**As a user**, I can ask a question in the chat so that I receive a synthesized answer drawn from my vault, with references to the specific wiki pages it came from.

## Acceptance Criteria

- The response streams back in real time.
- The LLM can call `read_page` and `search_vault` tools to look up vault content before answering.
- The response includes inline `[[wikilink]]` citations to the pages it read.
- No vault writes occur for a query-only message.
- A `status` SSE event is emitted each time a retrieval tool is executed, telling the user what the LLM is doing (e.g. "Reading programming/go.md…").
- The agentic loop is capped at 15 total tool calls per request to prevent runaway loops.

## Design Notes

### Two retrieval tools

**`read_page`** — fetch the full content of a specific vault page.
```json
{ "path": "programming/go.md" }
```
Returns the full markdown. The LLM uses the index (already in the system prompt) to decide which page to read.

**`search_vault`** — keyword search across all vault markdown files.
```json
{ "query": "Go interfaces" }
```
Returns up to 10 results, each with `{ "path": "...", "snippet": "..." }`. Implemented as a case-insensitive grep walk over all `.md` files in the vault; the snippet is the matching line plus two lines of surrounding context.

### Agentic loop

Today, `save_to_vault` is called at the *end* of the stream (write-after-reply). The retrieval tools must be called *before* the final reply — the LLM needs the content to synthesize its answer. The loop runs inside a single `POST /api/chat` request:

```
stream → tool call detected →
  if save_to_vault      → execute, emit vault event, done
  if read_page/search   → execute, emit status event, append tool_result, loop (max 15)
  if no tool call       → stream is final answer, done
```

### Status SSE event

```
event: status
data: {"message": "Reading programming/go.md…"}
```

Emitted immediately before each retrieval tool executes. The frontend shows this as a transient italic line; it is replaced when the next `status` or `delta` event arrives.

### Search implementation

`vault.Manager.SearchPages(query string, maxResults int) ([]SearchResult, error)` walks all `.md` files recursively, performs a case-insensitive substring search line-by-line, and returns up to `maxResults` hits. Each hit includes the vault-relative path and a snippet (the matching line ± 2 lines of context, trimmed to 300 chars).

### Citations

The LLM naturally references pages using `[[wikilinks]]` once it has read their contents. No new UI work required for this story.
