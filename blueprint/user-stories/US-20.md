# US-20 — Restore chat history from Google Drive

**As a user**, I want my chat history automatically restored from Google Drive when I set up on a new machine so that my conversations are available immediately without manual intervention.

## Background

Depends on US-19 (the backup must exist in Drive before it can be restored). Restore is a startup-time operation: the server checks whether the local Pebble database is absent or empty before opening it, and if so downloads and extracts the Drive backup. This happens once at boot and is otherwise invisible to the user.

## Acceptance Criteria

- At server startup, before `pebble.Open`, if `drive_sync.enabled: true` and `drive_sync.pebble_backup.enabled: true`, the server checks whether `PEBBLE_PATH` is absent or an empty directory.
- If `PEBBLE_PATH` is absent/empty and `autowiki-pebble-backup.tar.gz` exists in the Drive vault folder, the backup is downloaded, extracted to `PEBBLE_PATH`, and then Pebble is opened normally.
- If `PEBBLE_PATH` already contains data, the restore step is skipped entirely — the existing database is used as-is.
- If no Drive backup exists (fresh install with no prior data), the restore step is a no-op and Pebble starts with an empty database.
- Restore errors (e.g. corrupt archive, Drive unreachable) are logged and cause the server to start with an empty database rather than failing to start.

## Implementation Checklist

### Group 1 — Restore logic (`internal/sync/backup.go`)

- [ ] Implement `RestoreIfNeeded(ctx context.Context, pebblePath string) error` on `BackupManager`:
  1. Stat `pebblePath`: if it exists and is non-empty, return nil immediately.
  2. Search the Drive vault folder for `autowiki-pebble-backup.tar.gz` (use `ListFolder` and filter by name).
  3. If not found, return nil (no-op).
  4. Download to a temp file, extract to `pebblePath`. Return any extraction error.
- [ ] Tests:
  - When `pebblePath` is missing and Drive backup exists, the extracted files match those in the backup.
  - When `pebblePath` already has data, `RestoreIfNeeded` returns nil without downloading.
  - When Drive backup does not exist, `RestoreIfNeeded` returns nil without error.
  - When the downloaded archive is corrupt, `RestoreIfNeeded` returns an error.

### Group 2 — Wire into startup

- [ ] In `cmd/server/main.go`, call `BackupManager.RestoreIfNeeded(ctx, cfg.PebblePath)` before `pebble.Open`. On error, log a warning and continue (empty database fallback).
- [ ] `BackupManager` must be constructable before Pebble is open (it needs the Drive client, which only requires the OAuth token stored separately). Adjust the constructor to accept a `tokener` interface rather than requiring the full `*pebble.DB` at construction time; the DB reference is set after `pebble.Open` via a `SetDB` method.
