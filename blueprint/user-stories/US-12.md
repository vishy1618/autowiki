# US-12 — Check dream state history

**As a user**, I can check when the dream state last ran and what it changed so that I have visibility into how my vault is being maintained.

## Acceptance Criteria

- The last run time and a plain-language summary of changes are available.
- If the dream state has never run, this is clearly indicated.

## Status: Complete

Implemented as part of US-11. The dream consolidator appends a dated entry (`## 2026-04-16 dream run`) to `log.md` after each successful run, including a list of changes made or "No changes made." if the vault was already tidy. Since the dream runs at most once per day (enforced by idempotency check), the date is a unique identifier per run. The model can read `log.md` via `read_page` when the user asks about dream history.
