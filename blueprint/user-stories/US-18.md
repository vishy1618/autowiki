# US-18 — Drive sync status

**As a user**, I want to see the current state of my Google Drive sync so that I know whether my vault is connected and up to date.

## Background

Depends on US-16 and US-17. This story adds observability: a `GET /api/drive/status` API endpoint and a minimal status indicator in the UI. No new sync logic is introduced.

## Acceptance Criteria

- `GET /api/drive/status` (auth-guarded) returns:
  ```json
  {
    "enabled": true,
    "connected": true,
    "last_vault_sync": "2026-04-20T10:30:00Z",
    "last_pebble_backup": null,
    "last_error": null
  }
  ```
  - `enabled`: reflects `drive_sync.enabled` from config.
  - `connected`: `true` if `drive:refresh_token` is present in Pebble; `false` if Drive sync is enabled but the user has not yet signed in with the Drive scope.
  - `last_vault_sync`: RFC3339 timestamp of the last successful upload or download, or `null` if none yet.
  - `last_pebble_backup`: RFC3339 timestamp of the last successful Pebble backup (from US-19), or `null`.
  - `last_error`: last sync error string, or `null` if the last operation succeeded.
- When `connected: false`, the UI displays a prompt explaining that the user needs to sign out and back in to grant Drive access.
- The UI shows `last_vault_sync` as a human-readable relative timestamp (e.g. "2 minutes ago") with an absolute tooltip.
- When `enabled: false`, the status endpoint still responds (with `enabled: false` and all other fields `null`) — it does not 404.

## Implementation Checklist

### Group 1 — API endpoint

- [ ] Implement `GET /api/drive/status` handler in a new `internal/sync/handler.go`. Reads `enabled` from config, `drive:refresh_token` presence for `connected`, and `drive_sync:last_vault_sync` / `drive_sync:last_pebble_backup` / `drive_sync:last_error` from Pebble state.
- [ ] Register the route in `internal/server/server.go` (auth-guarded).
- [ ] Tests:
  - Returns correct JSON when sync is enabled and connected.
  - Returns `connected: false` when refresh token is absent.
  - Returns `enabled: false` with null fields when sync is disabled.

### Group 2 — Frontend status indicator

- [ ] Add a Drive sync status indicator to the home route (e.g. a small icon or line in the sidebar/header area).
- [ ] On mount, fetch `GET /api/drive/status`. Poll every 60 seconds while the page is open.
- [ ] Render states:
  - Drive sync disabled: no indicator shown.
  - Enabled, not connected: amber warning with "Sign out and back in to enable Drive sync."
  - Enabled, connected, no error: green indicator with "Synced [relative time]" and absolute tooltip.
  - Enabled, connected, last error non-null: red indicator with the error message.
- [ ] `last_vault_sync` formatted with the same `formatRelative` helper already used for chat session timestamps.
