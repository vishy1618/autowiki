# US-01 — Sign in with Google

**As a user**, I can sign in to autowiki using my Google account so that my personal knowledge base is protected and only accessible to me.

## Acceptance Criteria

- Navigating to the app when unauthenticated redirects to a sign-in page.
- Only the configured email address can successfully sign in; any other Google account is rejected with a clear message.
- After successful sign-in, I am redirected to the main chat interface.

## Implementation Checklist

### Config
- [x] Add `auth` block to `config.yaml` schema: `google_client_id`, `google_client_secret`, `allowed_email`, `session_secret`
- [x] Load and validate auth config at server startup — fail fast if any field is missing

### Backend — Pebble Store (`internal/store`)
- [x] Initialise Pebble at server startup
- [x] Define key schema for auth sessions: `auth:sessions:{token}` → `{ email, created_at, expires_at }`
- [x] Implement session creation, lookup, and deletion

### Backend — OAuth Flow (`internal/auth`)
- [x] Register `GET /api/auth/login` — builds Google OAuth URL and redirects
- [x] Register `GET /api/auth/callback` — exchanges code for token, fetches email from Google
- [x] Reject with 403 if returned email does not match `allowed_email`
- [x] On success, generate a signed session token and store it in Pebble with expiry
- [x] Set session token as a `Secure`, `HttpOnly`, `SameSite=Lax` cookie
- [x] Redirect to `/` after successful sign-in

### Backend — Auth Middleware
- [x] Implement middleware that validates the session cookie on every request
- [x] Apply middleware to all `/api/*` routes except `/api/auth/login` and `/api/auth/callback`
- [x] Unauthenticated `/api/*` requests return `401 Unauthorized`
- [x] Unauthenticated non-API requests redirect to `/login`

### Frontend — Sign-in Page (`/login`)
- [x] Create `/login` route in Remix
- [x] Render "Sign in with Google" button that links to `/api/auth/login`
- [x] Display rejection message if redirected back with an `?error=unauthorized` query param
- [x] Redirect to `/` if already authenticated

### Frontend — Auth Guard
- [x] All routes except `/login` check for a valid session; redirect to `/login` if absent
