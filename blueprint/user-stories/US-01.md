# US-01 — Sign in with Google

**As a user**, I can sign in to autowiki using my Google account so that my personal knowledge base is protected and only accessible to me.

## Acceptance Criteria

- Navigating to the app when unauthenticated redirects to a sign-in page.
- Only the configured email address can successfully sign in; any other Google account is rejected with a clear message.
- After successful sign-in, I am redirected to the main chat interface.

## Implementation Checklist

### Config
- [ ] Add `auth` block to `config.yaml` schema: `google_client_id`, `google_client_secret`, `allowed_email`, `session_secret`
- [ ] Load and validate auth config at server startup — fail fast if any field is missing

### Backend — OAuth Flow (`internal/auth`)
- [ ] Register `GET /api/auth/login` — builds Google OAuth URL and redirects
- [ ] Register `GET /api/auth/callback` — exchanges code for token, fetches email from Google
- [ ] Reject with 403 if returned email does not match `allowed_email`
- [ ] On success, generate a signed session token and store it in RocksDB with expiry
- [ ] Set session token as a `Secure`, `HttpOnly`, `SameSite=Lax` cookie
- [ ] Redirect to `/` after successful sign-in

### Backend — Auth Middleware
- [ ] Implement middleware that validates the session cookie on every request
- [ ] Apply middleware to all `/api/*` routes except `/api/auth/login` and `/api/auth/callback`
- [ ] Unauthenticated `/api/*` requests return `401 Unauthorized`
- [ ] Unauthenticated non-API requests redirect to `/login`

### Backend — RocksDB Session Storage
- [ ] Define key schema for auth sessions: `auth:sessions:{token}` → `{ email, created_at, expires_at }`
- [ ] Implement session creation, lookup, and deletion

### Frontend — Sign-in Page (`/login`)
- [ ] Create `/login` route in Remix
- [ ] Render "Sign in with Google" button that links to `/api/auth/login`
- [ ] Display rejection message if redirected back with an `?error=unauthorized` query param
- [ ] Redirect to `/` if already authenticated

### Frontend — Auth Guard
- [ ] All routes except `/login` check for a valid session; redirect to `/login` if absent
