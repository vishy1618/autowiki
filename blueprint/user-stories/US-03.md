# US-03 — Basic streaming chat

**As a user**, I can type a message and receive a streaming reply from an LLM assistant so that I can have a real-time conversation.

## Acceptance Criteria

- The assistant's reply streams into the UI token by token.
- Messages are persisted in the chat history store.
- A new chat session is created automatically; if there has been no activity for 30 minutes, subsequent messages start a fresh session.

## Implementation Checklist

### Chat History Store (`internal/store`)
- [ ] Define `ChatSession` model: `id`, `created_at`, `last_active_at`
- [ ] Define `Message` model: `id`, `session_id`, `role` (user|assistant), `content`, `created_at`
- [ ] Add `ChatStore` interface: `ResolveSession() (ChatSession, error)`, `AppendMessage(Message) error`, `ListMessages(sessionID string) ([]Message, error)`
- [ ] Implement `ChatStore` against Pebble using the key schema from TRD §4.6
- [ ] Unit tests via shared suite (MemChatStore + PebbleChatStore)

### LLM Client (`internal/llm`)
- [ ] Define `Client` struct that calls the Anthropic Messages API
- [ ] `Stream(ctx, messages []Message) (io.ReadCloser, error)` — opens a streaming request and returns the raw SSE body for the caller to consume
- [ ] Unit tests with a stubbed HTTP transport

### Chat Handler (`internal/chat`)
- [ ] Define `Handler` struct wiring `ChatStore` and `llm.Client`
- [ ] Register `POST /api/chat` (protected by auth middleware), field `message` (plain text)
- [ ] Resolve or create the active session via `ChatStore.ResolveSession`
- [ ] Persist the user message via `ChatStore.AppendMessage`
- [ ] Call `llm.Client.Stream`, forward token deltas to the client as SSE `delta` events: `data: {"text":"..."}`
- [ ] After stream ends: persist the assembled assistant message
- [ ] Emit SSE `done` event: `data: {"session_id":"..."}`
- [ ] Handler tests using stubbed LLM and in-memory store

### Frontend — Chat UI
- [ ] Replace home route placeholder with a chat layout: scrollable message thread + input bar at the bottom
- [ ] Input bar: textarea + send button; submit on Enter (Shift+Enter for newline)
- [ ] On send: `POST /api/chat` with `fetch`, open the SSE response stream
- [ ] Render `delta` events as streaming text on the in-flight assistant bubble
- [ ] On `done`: finalise the assistant bubble, re-enable input
- [ ] On error: display an inline error message, re-enable input
- [ ] Show a typing indicator while the stream is in flight
