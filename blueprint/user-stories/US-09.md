# US-09 — Scroll back through chat history

**As a user**, I can scroll back through my entire chat history in a single continuous view so that I can recall any past conversation or piece of knowledge I have shared, regardless of when it occurred.

## Acceptance Criteria

- The chat interface presents all messages as one unbroken timeline, with no visible concept of sessions.
- Scrolling up continuously loads older messages without requiring any user action beyond scrolling.
- The most recent messages are shown on load; older messages are fetched progressively as the user scrolls up.
