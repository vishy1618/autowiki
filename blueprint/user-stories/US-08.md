# US-08 — Browse vault in Obsidian

**As a user**, I can open my Obsidian vault at any time and navigate my wiki as ordinary markdown files so that I can read and explore my knowledge base independently of the autowiki interface.

## Acceptance Criteria

- All pages use standard Obsidian `[[wikilink]]` syntax to cross-reference related pages wherever appropriate.
- Pages are organised in human-readable, topic-based folders with prose content.
- A `schema.md` file in the vault root documents the wiki conventions (folder structure, linking style, writing style, heading conventions). If it does not exist when a chat request arrives, it is created from a built-in template before the LLM processes the request, so every response is informed by the schema.
- `schema.md` is read on every request and injected into the LLM system prompt as a dedicated section alongside the vault index.
- The LLM follows the conventions in `schema.md` for all vault writes. It only modifies `schema.md` itself when the user explicitly asks it to update the wiki conventions.

## Default schema.md template sketch

```markdown
# Wiki Schema

## Folders
Lowercase, topic-based. Nest only when a topic grows large.
Examples: `programming/go.md`, `science/biology/cell-theory.md`

## Files
Lowercase hyphenated noun phrases. Example: `go-interfaces.md`

## Links
Use `[[wikilinks]]` to connect related pages. Link on first meaningful mention.

## Headings
H1 for page title, H2 for major sections, H3 for subsections.

## Style
Concise present-tense prose. Bullet lists for enumerations and steps, not explanations.
```
